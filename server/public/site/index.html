安装 安全说明

Chrome / Edge 扩展

把 ChatGPT 网页登录状态转换成 Codex 可用凭证。

在已登录 ChatGPT 的浏览器里读取 session，生成可复制的 auth.json，减少 Codex 登录时反复手机验证的麻烦。

02

03

接收通知

插件内支持消息同步，用于版本提醒和使用公告。

安装方式

下载 zip，解压后加载扩展。

  1. 点击“下载插件”，保存 zip 文件并解压。
  2. 打开 Chrome 或 Edge 的 chrome://extensions。
  3. 打开右上角“开发者模式”。
  4. 点击“加载已解压的扩展程序”，选择包含 manifest.json 的文件夹。
  5. 登录 https://chatgpt.com 后，点击扩展图标打开侧边栏。

安全说明

凭证只用于你自己的 Codex 登录。

auth.json、access_token、id_token 都属于敏感信息，不要发送给他人。插件消息同步只使用安装 ID、版本和消息状态，不上传完整 session 或 auth.json。
