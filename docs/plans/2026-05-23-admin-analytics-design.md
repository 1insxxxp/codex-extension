# 后台访问统计设计

## 目标

把现有 Codex 消息后台升级为后台管理系统，在同一个登录态下展示插件消息管理和官网访问统计。

## 统计口径

- `page_view`: 用户打开首页 `/` 时由服务端记录。
- `download_click`: 用户点击首页下载按钮时由前端发送埋点。
- `download_file`: 用户实际请求插件 zip/crx 文件时由服务端记录。
- 独立访客按每天的 `IP + User-Agent` 哈希去重，只保存哈希，不保存原始 IP。

## 架构

统计数据继续写入现有 `server/data/server.json`，新增 `analytics_events` 数组。服务端新增轻量记录函数和汇总函数，后台通过 `/admin/api/analytics` 获取汇总数据。公网只开放 `/api/analytics/event` 用于记录下载点击，不提供公开读取接口。

## 后台界面

保留 `/admin/messages` 路径，但页面标题改为 Codex 后台管理系统。页面顶部显示统计概览，包含今日访问、今日独立访客、今日下载点击、今日实际下载和累计值；下方保留消息创建、安装记录和历史消息。

## 测试

服务端测试覆盖：

- 首页访问会记录 `page_view`。
- 下载文件请求会记录 `download_file`。
- 下载点击埋点接口会记录 `download_click`。
- 后台统计接口必须登录。
- 统计汇总返回今日、累计和最近 7 天数据。
